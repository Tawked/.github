Tawked (توكيد) is a Saudi messaging platform at [tawked.com](https://tawked.com) and a Meta Tech Provider: businesses send WhatsApp Business API notifications from their own number and SMS OTP verification codes, and answer customers in Tawked Chat, a shared WhatsApp inbox for teams. Tawked Email, in early access, sends a business's mail from its own domain.

### Products

| Product | What it does | Docs |
|---|---|---|
| [Tawked Verify](https://tawked.com/en/verify) | One-time codes by SMS to Saudi mobile numbers: one call sends the code, a second checks it | [Quickstart](https://docs.tawked.com/quickstart) |
| [WhatsApp Business API](https://tawked.com/en/whatsapp) | Meta-approved template messages to your customers from your business's own number | [Quickstart](https://docs.tawked.com/whatsapp/quickstart) |
| [Tawked Chat](https://tawked.com/en/chat) | A shared WhatsApp inbox for your team, on the web, iPhone and Android | [For apps](https://docs.tawked.com/chat) |
| [Tawked Email](https://tawked.com/en/email) (Early Access) | Transactional email from your own verified domain | [Quickstart](https://docs.tawked.com/email/quickstart) |

### SDKs

| Language | Package | Install |
|---|---|---|
| JavaScript and TypeScript | [`@tawked/sdk`](https://github.com/tawked/tawked-node) | `npm install @tawked/sdk` |
| PHP | [`tawked/tawked-php`](https://github.com/tawked/tawked-php) | `composer require tawked/tawked-php` |
| Python | [`tawked`](https://github.com/tawked/tawked-python) | `pip install tawked` |
| Laravel | [`tawked/laravel`](https://github.com/tawked/tawked-laravel) | `composer require tawked/laravel` |
| Better Auth | [`@tawked/better-auth`](https://github.com/tawked/tawked-better-auth) | `npm install @tawked/better-auth better-auth` |

The JavaScript, PHP and Python SDKs cover every product, the Partner API for platforms, the Account API for scripts and AI agents, and the signatures of Tawked's webhooks. The Laravel and Better Auth packages are built on them. All five are MIT licensed.
